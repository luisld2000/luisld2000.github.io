# Sitio público de Madera Industrial

Páginas públicas que Google exige para poder publicar la pantalla de consentimiento OAuth
de la app:

- `index.html` — presentación de la app (URL de página principal).
- `privacidad.html` — política de privacidad.

Se sirven con GitHub Pages en <https://luisld2000.github.io/>.

La app en sí **no** está aquí: vive en el repositorio privado
[`luisld2000/maderaindustrial`](https://github.com/luisld2000/maderaindustrial).

El repositorio se llama `luisld2000.github.io` a propósito: con ese nombre GitHub publica el
sitio en la raíz del dominio, que es lo que Google Search Console verifica como propiedad y
lo que se declara en «Dominios autorizados» de la consola de OAuth.
